## 🖥️ How to Capture Screenshots on Windows

1. Open the target URL in Google Chrome, Microsoft Edge, or Firefox.
2. Press `Win + Shift + S` to open the Windows Snipping Tool.
3. Select the browser window or region you wish to capture.
4. Save the captured image into this directory (`docs/screenshots/`) using the filenames listed above.
5. In your Word or PDF report submission, embed the images with the corresponding captions from the table.
